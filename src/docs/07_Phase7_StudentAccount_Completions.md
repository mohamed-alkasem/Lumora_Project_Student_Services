# Phase 7 — كماليات حساب الطالب والتدفق الكامل

## الهدف
إكمال دورة الطالب من أولها لآخرها: تفاصيل الجامعة ← طلب استشارة يصل للأدمن ← مفضلة مرتبطة بالحساب ← إدارة الحساب (بيانات + كلمة مرور) ← رسائل أخطاء مترجمة بالكامل.

## 1. صفحة تفاصيل الجامعة (عامة — بدون تسجيل)
- `UniversitiesController.Details(id)` → [Views/Universities/Details.cshtml](../Lumora.Web/Views/Universities/Details.cshtml) + `wwwroot/css/pages/university-details.css`.
- Hero بلون النوع (كحلي=حكومية / ذهبي=خاصة) مع الشعار والتقييم والموقع، قسم "عن الجامعة"، رقائق "التخصصات المتاحة"، وكرت CTA لاصق فيه الرسوم وزر "قدّم الآن".
- **روابط البطاقة**: اسم الجامعة وزر "+" صارا يوصلان للتفاصيل.

## 2. طلب الاستشارة (يصل لصندوق الأدمن)
- `ConsultationsController` (عام) بأكشن `Request` GET/POST محمي بـ `[Authorize(Roles=Student)]` — الزائر غير المسجل يُحوَّل للدخول/التسجيل ويرجع لنفس الصفحة تلقائياً (سلوك `returnUrl` المدمج).
- النموذج **مُعبّأ مسبقاً** باسم الطالب وهاتفه من حسابه، ويعرض اسم الجامعة عندما يأتي من زر "قدّم الآن" في بطاقة/تفاصيل جامعة (`universityId` بالرابط). الرسالة اختيارية.
- بعد الإرسال: Toast نجاح + الطلب يظهر فوراً في **Admin → Consultations** بحالة "جديد" مع اسم الجامعة والرسالة، وعدّاد الـ Dashboard يتلوّن.
- **الربط**: زر "قدّم الآن" بكل بطاقة، كرت CTA بصفحة التفاصيل، وزر "استشارة مجانية" الذهبي بالـ Navbar — كلها توصل للنموذج.

## 3. صفحة المفضلة `/Favorites`
- `FavoritesController.Index` (Student فقط) تستخدم `GetMyFavoritesAsync` وتعيد نفس بطاقة الجامعة المشتركة.
- هيدر بعدّاد، والقلب بيشيل البطاقة فوراً من الشبكة (AJAX) مع حالة فارغة "لا توجد جامعات..." وزر تصفح.
- ملفات معزولة: `css/pages/favorites.css` + `js/pages/favorites.js`.
- رابط "مفضلتي" بقائمة الحساب المنسدلة بالـ Navbar.

## 4. إدارة الحساب (لأي مستخدم مسجل)
- `/Account/Profile`: تعديل الاسم الكامل ورقم الهاتف (البريد للعرض فقط — لا يُؤخذ من الفورم أبداً).
- `/Account/ChangePassword`: كلمة الحالية + الجديدة + التأكيد عبر `ChangePasswordAsync`، مع `RefreshSignInAsync` لإبقاء الجلسة الحالية (والجلسات الأخرى تسقط بتغير الـ SecurityStamp).
- **Navbar dropdown** جديد بدل الاسم المجرد: مفضلتي (للطالب) / لوحة التحكم (للأدمن) / الملف الشخصي / خروج.
- الـ Layout العام صار يعرض `TempData["Success"/"Error"]` كـ Alerts (كان للأدمن فقط).

## 5. ترجمة أخطاء Identity
[Services/LocalizedIdentityErrorDescriber.cs](../Lumora.Web/Services/LocalizedIdentityErrorDescriber.cs) يترجم: بريد مكرر، بريد غير صالح، قواعد كلمة المرور (طول/رقم/صغير/كبير)، وكلمة المرور الحالية الخاطئة.
**نقطة تسجيل حرجة**: يُسجَّل في `Program.cs` **قبل** `AddInfrastructure` لأن `AddIdentity` يستخدم `TryAddScoped` — أول تسجيل يفوز. تحقّقنا فعلياً: التسجيل بكلمة ضعيفة على الواجهة العربية يعرض "يجب أن تحتوي كلمة المرور على رقم/حرف كبير..." بلا أي تسريب إنكليزي.

## 6. إعادة هيكلة CSS البطاقة
ستايلات `uni-card-*` + الحالة الفارغة انفصلت من `pages/universities.css` إلى **`css/components/university-card.css`** لأنها صارت مشتركة بين 3 صفحات (الدليل، المفضلة، وأي صفحة قادمة). أُضيف glob `css/components/**/*.css` لتصغير WebOptimizer.

## 7. مفاتيح ترجمة جديدة
~24 مفتاحاً × 5 لغات (حسابي، مفضلتي، طلب استشارة، تم استلام طلبك...، أخطاء كلمة المرور، إلخ).

## نتائج E2E (curl + كوكيز + Anti-Forgery)
| السيناريو | النتيجة |
|---|---|
| تسجيل طالبة جديدة → دخول تلقائي | ✓ |
| صفحة تفاصيل جامعة (اسم + 3 تخصصات) | ✓ |
| قلب AJAX → `{isFavorite:true,count:1}` → صفحة المفضلة فيها البطاقة والعدّاد | ✓ |
| نموذج الاستشارة معبّأ مسبقاً وعارض "Koç University" → إرسال → **ظهر بصندوق الأدمن** بحالة جديد + الرسالة | ✓ |
| تغيير كلمة المرور → **الدخول بالجديدة نجح** والقديمة انتهت | ✓ |
| تحديث الملف الشخصي وحُفظ | ✓ |
| أخطاء كلمة ضعيفة بالعربية (رقم/حرف كبير) بلا تسريب إنكليزي | ✓ |
| الطالبة ظهرت بقائمة Students بالأدمن | ✓ |
| تنظيف بيانات الاختبار (استشارة/مفضلة/حساب) | ✓ |

## مصيدة اختبار (للوكيل القادم)
بعد تسجيل الدخول صار بالصفحة **توكنا** Anti-Forgery (فورم الصفحة + فورم الخروج بالـ Navbar dropdown) — عند الاختبار بـ curl خُذ الأول فقط (`head -1`) وإلا يتشوّه المتغير ويرجع 400. (أي توكن منهما صالح فعلياً؛ المشكلة فقط في التقاط متعدد الأسطر.)
