# Phase 10 — معارض الصور + البريد + نظام الأنيميشن + التجاوب

## 1. معارض صور متعددة (جامعات + سكن)

### قاعدة البيانات (Migration: `AddGalleryImages`)
- `UniversityImages` و `HousingImages`: (Id, FK, Url(500), DisplayOrder) + فهرس (FK, DisplayOrder)، Cascade مع الأب، وCollections `Images` على الكيانين.
- `GetWithDetailsAsync` بالمستودعين صار يعمل Include للصور (غير المحذوفة، مرتبة).
- DTOs: `ImageUrls` على `UniversityDetailsDto` و `HousingDetailsDto` + `GalleryImageDto` مشترك في `DTOs/Base`.
- خدمات: `GetImagesAsync` / `AddImageAsync` / `RemoveImageAsync` على `IUniversityService` و `IHousingService` (الحذف يعيد الـ URL لتنظيف الملف الفعلي).

### لوحة الأدمن
- Partial مشترك `Areas/Admin/Views/Shared/_GalleryManager.cshtml` يظهر أسفل شاشة **تعديل** الجامعة/السكن: شبكة مصغرات مع زر ✕ للحذف (مع تأكيد) + رفع **عدة ملفات دفعة واحدة** (`galleryFiles` multiple). أكشنات `UploadImages`/`DeleteImage` بالكنترولرين مع نفس تحقق `AdminUpload` (2MB، امتدادات محددة).

### الموقع العام
- مكوّن معرض `css/components/gallery.css` + `js/pages/gallery.js`: صورة رئيسية 16:9 بانتقال Fade + سهمان (ينعكسان بالـ RTL) + عدّاد "2 / 5" + شريط مصغرات قابل للتمرير + أسهم الكيبورد. مركّب بصفحتي التفاصيل ويظهر فقط عند وجود صور.
- **E2E فعلي:** رفع صورتين PNG عبر multipart → ظهرتا بشبكة الأدمن وبمعرض صفحة الجامعة العامة (بقيتا كعينة demo على جامعة بوغازيتشي — بدّلهما بصور حقيقية).

## 2. البريد (SMTP)
- `IEmailSender` في Domain، والتنفيذ `Infrastructure/Email/SmtpEmailSender` بـ `SmtpOptions` من قسم `"Smtp"` بالـ appsettings (Host/Port/User/Password/From/FromName/EnableSsl).
- **بدون إعداد Host يتخطى الإرسال بهدوء مع سطر لوغ** — ما بينكسر شي بالتطوير. عند تعبئة بيانات مزود حقيقي (Gmail App-Password / SendGrid...) بيشتغل فوراً.
- **إيميل ترحيبي عند تسجيل الطالب** بلغة المتصفح الحالية (مفاتيح `WelcomeEmailSubject/Body` ×5 لغات، الاسم بـ {0})، Fire-and-forget داخل try/catch — فشل البريد لا يمنع التسجيل أبداً. مُتحقق منه: سطر "SMTP not configured — skipped email to..." ظهر باللوغ عند تسجيل حساب اختباري.

## 3. اللوغو
`.lum-logo { direction: ltr }` — كلمة LUM●RA ما عادت تنعكس حروفها تحت `dir="rtl"` وبتضل بكل اللغات بنفس الشكل.

## 4. أيقونات سريعة بالـ Navbar
قلب (مفضلتي) وفقاعة محادثة (مع **نقطة ذهبية نابضة Ping**) كأزرار دائرية دائمة الظهور بجانب زر الاستشارة، مع Tooltip تحتها وهوفر بألوان مميزة. زر "استشارة مجانية" النصي صار يظهر من lg وطالع (الأيقونات بتغني عنه بالموبايل).

## 5. نظام الأنيميشن العام
- **Reveal-on-scroll** (`site.js` + قواعد `[data-reveal]` بالثيم): IntersectionObserver يضيف `.is-revealed`؛ أنواع: افتراضي (صعود)، `left/right` (انزلاق)، `zoom`؛ تأخير تدريجي عبر `--reveal-delay`؛ **يحترم `prefers-reduced-motion`**.
- **عدادات متحركة** `[data-count-to]` بـ Easing (ease-out cubic): إحصائيات الرئيسية 5000+/120+/10+/98% بتعد تصاعدياً عند وصولها للشاشة.
- **دخول الـ Hero** بالرئيسية: العناصر بتطلع متتالية عند التحميل (بدون سكرول).
- **ظل الـ Navbar عند التمرير** (`.is-scrolled`).
- مطبق عالرئيسية: بطاقات الخدمات (تتابع 0.1s)، الميزات (Zoom متتالي)، الخطوات الخمس، الآراء، بلوك السكن (يسار/يمين)، وCTA.

## 6. التجاوب (موبايل + آيباد)
- **أدمن < 992px:** السايدبار يتحول لصف أفقي قابل للتمرير (Pills)، حشوات أصغر.
- الشريط العائم أصغر بالموبايل وبدون Tooltips؛ التوپبار أصغر والإيميل مخفي بالشاشات الضيقة (كان أصلاً)؛ Hero والأقسام حشوة أقل < 576px؛ ترقيم الصفحات صار يلتف (flex-wrap) بالجامعات والسكن؛ كل الشبكات أصلاً بـ Breakpoints (4→2→1).
