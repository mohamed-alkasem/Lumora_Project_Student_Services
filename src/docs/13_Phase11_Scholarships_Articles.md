# Phase 11 — صفحة المنح + صفحة المقالات + تحسينات

## 1. المنح (Scholarships)

### الفكرة (طلب المالك)
عروض مقاعد جامعية: السعر الأصلي **مشخوط** (مثلاً ~~$10,000~~) وبجانبه السعر بعد الخصم ($5,000) مع نسبة الخصم — لكل منحة جامعة مرتبطة وصورة وموعد نهائي.

### قاعدة البيانات (Migration: `AddScholarshipsAndArticles`)
- `Scholarships`: UniversityId (FK Cascade)، OriginalPriceUsd، DiscountedPriceUsd (decimal 10,2)، ImageUrl، Deadline (اختياري)، IsActive، DisplayOrder.
- `ScholarshipTranslations`: Title(200) + Description(2000)، فهرس فريد (ScholarshipId, LanguageCode).

### الطبقات
- DTOs في `DTOs/Scholarships/` — الـ Card يحسب **`DiscountPercent`** تلقائياً من السعرين.
- `IScholarshipService`/`ScholarshipService`: CRUD كامل + `GetActiveAsync(lang)` للفعالة فقط (مرتبة DisplayOrder ثم الأحدث). أسماء الجامعات تُجلب بجلبة واحدة مترجمة وتُوزع بالقاموس (الجامعات lookup صغير).
- **أدمن** `Admin/Scholarships`: جدول فيه السعر الأصلي مشخوط + المخفض + شارة `-X%` + Active/Inactive؛ نموذج بتبويب 5 لغات + قائمة الجامعات + سعرين + تاريخ نهائي (date input) + صورة.
- **عام** `/Scholarships`: Hero كحلي + شبكة كروت: صورة/أيقونة + **شارة خصم حمراء نابضة** `-50%` + Chip باسم الجامعة + وصف مقصوص + **سعر قديم مشخوط بخط أحمر وسعر جديد ذهبي كبير** + سطر الموعد النهائي + "قدّم الآن" (يذهب للاستشارة بالجامعة المحددة) + "عن الجامعة". مع Reveal متدرج.

## 2. المقالات (Articles)

### قاعدة البيانات
- `Articles`: CoverImageUrl، IsPublished.
- `ArticleTranslations`: Title(200)، Summary(500)، **Body (nvarchar(max))** — فقرات مفصولة بأسطر فارغة.

### الطبقات
- `IArticleService`/`ArticleService`: CRUD + `GetPublishedAsync(lang)` (الأحدث أولاً).
- **أدمن** `Admin/Articles`: جدول (غلاف/عنوان/تاريخ/حالة) + نموذج بتبويب 5 لغات (عنوان + ملخص + محتوى textarea 10 أسطر) + غلاف.
- **عام** `/Articles`: كروت بغلاف بيتكبر بالهوفر (Zoom) + تاريخ ذهبي + ملخص مقصوص + "اقرأ المزيد" بسهم بينعكس RTL. `/Articles/Details/{id}`: Hero بالعنوان والملخص + **الغلاف طالع فوق الـ Hero** (Overlap أنيق) + الجسم مقسّم فقرات `<p>` تلقائياً + أزرار عودة/استشارة. غير المنشور بيرجع 404.

## 3. الربط
- روابط **المنح والمقالات** بالـ Navbar (مع حالة Active وتضييق حشوة الروابط لتتسع الثمانية) وبالـ Footer (روابط سريعة) وبسايدبار الأدمن.
- 14 مفتاح ترجمة جديد × 5 لغات.
- **بيانات تجريبية**: 3 منح (كوتش 50%، بيلكنت 50%، مديبول 38% — وهذه بالضبط حالة "10000→5000") و3 مقالات كاملة بفقرات (en/ar/tr) بحارسين مستقلين بالـ Seeder.

## ملحق — إصلاح رفع الصور (نفس الجلسة)
**المشكلة (بلاغ المالك):** "الصور ما عم تنرفع للمقالات والمنح" — السبب الجذري: حد الرفع كان **2MB** وصور الهاتف/الكاميرا الحقيقية 3-15MB فكانت تُرفض.

**الحل:**
1. **معالجة صور تلقائية بالسيرفر** عبر `SixLabors.ImageSharp` **3.1.11** (⚠️ الإصدار 4 يتطلب ترخيصاً تجارياً وقت البناء — لا ترقِّه): في `LocalFileStorageService.SaveAsync` كل صورة نقطية (png/jpg/webp) تمر بـ: تصحيح دوران EXIF (`AutoOrient`) → تصغير لأقصى بعد **1920px** إن كانت أكبر → إعادة ترميز (JPEG جودة 82 / WebP جودة 80 / PNG يحافظ على الشفافية للشعارات). SVG يمر كما هو. فشل المعالجة (ملف تالف) يسقط بأمان لنسخ الملف الخام مع سطر لوغ.
2. **حد الرفع 2MB → 15MB** في `AdminUpload.MaxBytes` + تحديث رسالة `ImageTooLarge` بالخمس لغات.
3. المسار واحد مشترك — الإصلاح يشمل تلقائياً: أغلفة المقالات، صور المنح، الشعارات، صور الآراء، السكن، وكل المعارض.

**اختبار فعلي:** صورة PNG بحجم **14.4MB** وأبعاد **3000×2000** رُفعت عبر endpoint المعرض → 302 → حُفظت **2.8MB بأبعاد 1920×1280** ✓ (وصورة 16.7MB فوق الحد رُفضت برسالة مهذبة كما يجب). نُظفت صور الاختبار بعدها.
